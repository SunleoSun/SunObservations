# sun-observations-derive

Procedural macro companion for [sun-observations](https://crates.io/crates/sun-observations).

It provides the Observation and DomainInput derives used by the main package. Applications should normally depend on sun-observations, which re-exports these macros.

Documentation, examples, and agent-facing guides live in the [SunObservations repository](https://github.com/SunleoSun/SunObservations) and the main sun-observations package.
